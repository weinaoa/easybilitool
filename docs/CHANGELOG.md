# 更新记录

## 1.1.16 — 2026-11-14

- 修复沉浸状态栏开启后，普通视频和竖屏视频的原生长按倍速提示进入状态栏的问题，按播放器范围、可见系统栏和摄像头区域定位。
- 适配竖屏 Story 的 Compose 倍速提示层，与普通提示采用同一安全间距；关闭沉浸状态栏时保留原生布局。
- 交付改用 R8 Release，启用代码优化、混淆、代码与资源裁剪，保留原签名和现代 LSPosed 入口。独立构建及实机范围见[验证记录](../qa/PLAYER-TIP-v1116.md)。

## 1.1.15 — 2026-10-28

- 新增“运行日志”，保留最近的模块、窗口、播放器表面和触摸状态，后台写入、双文件轮转，总量最多 512 KB；支持标记问题、暂停本次记录、复制、导出和清空。
- 视频页更新布局时保留当前绘制帧，缓解取消整帧绘制造成的闪黑风险。偶发黑闪尚未稳定复现，记录明确区分兼容性调整和有限样本的检查结果。
- 日志只记录本模块的技术事件，不采集账号、页面文字或视频内容。入口和独立实机范围见[播放器与日志验证](../qa/PLAYER-LOG-v1115.md)。

## 1.1.14 — 2026-10-27

- 修复竖屏全屏直播间状态栏与画面之间的明暗断层，使用 Android 官方 Jetpack WindowCompat 实现边到边，并由系统 Insets 保留交互控件的顶部安全距离。
- 旧直播遮罩退出本功能的沉浸路径，状态栏渐变继续交给 AndroidX ProtectionLayout / GradientProtection；关闭保护时保持透明。
- 关闭导航栏沉浸时保留内容的底部安全区，使用官方 ColorProtection 保留底部背景；键盘往返与退出页面后恢复原布局。
- 构建、APK 审计、实机范围及限制见[直播状态栏验证](../qa/LIVE-STATUS-v1114.md)。

## 1.1.13 — 2026-10-24

- 修复原生底栏和补出的导航安全区背景仅遮挡画面、点击仍能打开下方内容的问题。
- 触摸拦截跟随安全区所属视图，保留从正文开始的滑动；背景收起、导航沉浸关闭及键盘往返时清理对应拦截。
- 增加完整触摸序列、边界、多指、取消和恢复检查。验证范围见[安全区点击回归](../qa/NAV-SAFE-TOUCH-v1113.md)。

## 1.1.12 — 2026-10-24

2026-10-24 从 `compat/bili-9161` 合入 `main`，发布附件见 [v1.1.12](https://github.com/weinaoa/easybilitool/releases/tag/v1.1.12)。以 1.1.6 为基线整理维护者提供的 1.1.11 源码包，保留旧版原生路径，增加官方客户端 9.16.1 适配。

- 适配 Compose 首页、动态正文与评论、视频评论、Story 竖屏及窗口安全区。
- 补齐底栏随手势连续下移、渐隐和反向恢复，避免二值显示切换；收起时释放列表空间并保留末项安全距离。
- 修正旧版原生回复页的顶部避让，以及新版动态与分享面板的导航背景延伸。
- 稳定普通视频评论键盘往返的窗口布局，随系统键盘动画连续补足导航安全距离。
- 增加运行诊断、宿主静态契约审计及相关 JVM 检查。

最新补丁已在 9.16.1 独立实测，并用同一 APK 完成 [8.95.0 共用流程复测](../qa/OLD-HOST-RETEST-20261024.md)。请先阅读[验证索引](TESTING.md)，不要把不同 APK 的结果合并成一次完整验收。
