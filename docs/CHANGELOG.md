## 1.1.12 — 2026-10-24

2026-10-24 从 `compat/bili-9161` 合入 `main`，发布附件见 [v1.1.12](https://github.com/weinaoa/easybilitool/releases/tag/v1.1.12)。以 1.1.6 为基线整理维护者提供的 1.1.11 源码包，保留旧版原生路径，增加官方客户端 9.16.1 适配。

- 适配 Compose 首页、动态正文与评论、视频评论、Story 竖屏及窗口安全区。
- 补齐底栏随手势连续下移、渐隐和反向恢复，避免二值显示切换；收起时释放列表空间并保留末项安全距离。
- 修正旧版原生回复页的顶部避让，以及新版动态与分享面板的导航背景延伸。
- 稳定普通视频评论键盘往返的窗口布局，随系统键盘动画连续补足导航安全距离。
- 增加运行诊断、宿主静态契约审计及相关 JVM 检查。

最新补丁已在 9.16.1 独立实测，并用同一 APK 完成 [8.95.0 共用流程复测](../qa/OLD-HOST-RETEST-20261024.md)。请先阅读[验证索引](TESTING.md)，不要把不同 APK 的结果合并成一次完整验收。
