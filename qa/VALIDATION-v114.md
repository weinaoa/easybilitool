# 1.1.4 直播导航沉浸修复

日期：2026-10-18。简单版独立构建与验证，仍只有沉浸状态栏、滑动收起底栏、沉浸导航栏三个开关。

## 修复范围

- 直播底部控制区不再从输入框复制半透明圆角背景。宿主原背景、输入框与按钮背景保留，安全距离计算不变。
- “全部直播”关注网页限定到 HTTPS `live.bilibili.com/p/html/live-app-my-focus/index.html`。窗口和 WebView 祖先容器延伸到手势区，网页滚动容器保留至少实际导航高度的底部安全距离；网页原有距离足够时不重复累加。
- 不新增原生背景覆盖层。退出、关闭开关、换页或键盘出现时恢复自有容器与网页调整；其余网页继续原有处理。
- 参考 [Android WebView Insets](https://developer.android.com/develop/ui/views/layout/webapps/understand-window-insets) 和 [边到边布局指导](https://developer.android.com/codelabs/edge-to-edge)。仅包含简单版自有导航实现，没有引入完整版功能或私有设备资料。

直播间完成沉浸开启/关闭两组进房、真实键盘/原生表情面板往返，开启时另检查退出重进；额外大圆角背景未出现，原生输入框和按钮保留。测试未输入或发送弹幕、礼物或点赞。

动态正文、动态评论与视频评论完成沉浸开启/关闭两组上滑收起、下滑恢复、惯性、视频简介/评论切换、退出重进及键盘往返。检查收起后的底色与列表实际边界，未发现新增背景条或遮挡。补充滚动到有限动态评论结束提示，确认末项与手势区保持距离；视频评论持续分页，不宣称到达其全部评论末项。

“全部直播”网页完成深色/浅色沉浸开启、深色沉浸关闭检查，均覆盖上下滑、惯性、滚动末尾和退出重进。开启时 WebView 边界 `[0,211][1080,2340]` 与屏幕底边一致，网页 viewport 为 774 CSS px，安全距离 20 CSS px；末行完整显示，网页实际延伸到手势区，没有原生补色覆盖层。关闭时 WebView 恢复截止于 y=2285。当前 System WebView 为 150.0.7871.181，不推断所有内核与安卓版本兼容。

网页没有文本输入框，网页键盘场景不适用，真实键盘往返使用视频/动态评论和直播原生输入。恢复主题时先前复用设置行坐标未找到目标，随后改用当前界面实际文本与开关定位，已确认宿主深色开启、跟随系统关闭，与初始状态一致。简单版偏好已逐字节恢复。原始中断记录保留在外部本地归档，不记作通过证据。
