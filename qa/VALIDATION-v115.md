# 1.1.5 竖屏沉浸与最常访问横滑修复

日期：2026-10-22。只补齐简单版三个现有开关范围内的沉浸适配，主许可证仍为 Mulan PubL v2。

## 修改

- 将 8.95 的 StoryVideoActivity 纳入状态栏沉浸。原生播放器另保留一份状态栏高度的 viewport 顶部留白，只撤去这一项，保留其它参数和顶部操作区；配置或启动窗口晚于播放器就绪时重放待处理请求。
- 取消模块强制白色状态栏图标和额外渐变，保留宿主通过旧、新系统栏 API 请求的图标明暗；不宣称客户端会随任意视频帧自动变色。
- 最常访问 QuickConsumeActivity 绕过通用根容器底部填色，将安全距离放入各页原生列表内部，并允许列表绘制到手势区。安全距离计入原生列表超出窗口的部分；关闭、暂停、退出及容器替换时恢复。

参考 [Android 边到边布局指导](https://developer.android.com/codelabs/edge-to-edge) 与[系统栏图标说明](https://developer.android.com/develop/ui/views/layout/edge-to-edge#system-bar-icons)。没有加入勋章、播放器手势、悬浮底栏或其它完整版功能。
