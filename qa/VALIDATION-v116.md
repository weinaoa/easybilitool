# 1.1.6 官方状态栏渐变保护

日期：2026-10-22。新增“状态栏渐变保护”子选项，默认开启，仅在沉浸状态栏开启时生效；三项主功能首次安装仍关闭。

## 实现与规范

直接使用 AndroidX Core 1.17.0 的 ProtectionLayout / GradientProtection，不自行采样视频亮度、不重写渐变算法、不根据视频逐帧切换图标明暗。开启时按宿主图标明暗设置保护背景；关闭后完全透明，沿用宿主图标选择。白底配白色图标在关闭保护时仍可能不易辨认，这是该选项关闭后的显示效果。

DecorView 保留真实系统边衬供官方监视器处理，宿主内容层消费状态栏顶部边衬，避免保护层高度变成零或恢复顶部黑带。组件在暂停、退出、横屏等不适用状态时撤回，不绘制底部保护层，也不改宿主列表尺寸。

参考 [官方系统栏图标与保护指导](https://developer.android.com/develop/ui/views/layout/edge-to-edge#system-bar-protection)。AndroidX 和运行依赖保留 Apache-2.0，许可证与来源声明随 APK 附带；ProfileInstaller 启动优化组件不打包。AndroidX 的内部签名级动态接收器权限保留，没有网络、存储权限或 provider。

## 本地与 APK

离线构建、8 组 JVM 检查入口、Lint 通过；Lint 0 错误、26 警告。配置检查覆盖四个布尔选项的独立组合、默认值、草稿、保存重开，以及关闭保护后不被默认值覆盖。38 个源码类与打包类对应；官方 ProtectionLayout / GradientProtection 已打包，compileOnly API 未打包，唯一作用域为 tv.danmaku.bili。
