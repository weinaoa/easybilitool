# 1.1.2 我的页有限列表安全区验证

日期：2026-10-07。APK versionName `1.1.2`，versionCode 8。

## 复现与修复

USB umi 上，“我的页”滚到底后，关闭沉浸导航时最后一行的下边界为 y=2112；开启时变为 y=2167，下移 55px，进入底栏背景。底栏各页签的文字边界在两种配置下相同，并没有额外上移。有限列表无法像连续加载的信息流一样继续滚动，因此这个末项避让缺口会稳定出现在页面末尾。

55px 来自该设备实际的导航/强制手势安全区；正常窗口内容截止 y=2285，沉浸后可延伸至屏幕底部 y=2340。源码不写死 55px，也不缩减系统返回的安全距离。

- `MainContentSafeArea` 按列表实际下边界与窗口底部计算新暴露的导航区域，仅补齐缺少的末尾 padding。
- 只处理当前可见的 `mine_recycle`；保留宿主原有末尾留白，使用数值基线和弱引用键，切页、应用返回与宿主改写 padding 时不重复累加。
- 列表使用 `clipToPadding=false`，允许内容滑过背景延伸区；真正滚到底时仍避让控件。离开或关闭时按本模块写入值核对并恢复。

适配依据：[Android 边到边 Codelab](https://developer.android.com/codelabs/edge-to-edge?hl=zh-cn#5) 的内容安全区和滚动列表 padding 原则。模块沿用宿主窗口的状态栏、键盘和导航显示处理，本次校正有限列表末项距离。

## 实机范围

Xiaomi 10 / umi（明确指定 USB 设备），Android 17 / API 37，1080×2340，哔哩哔哩 8.95.0（8950600）。测试前备份配置及模块状态；每一工程测试时只有该模块启用并作用于宿主。

“我的页”覆盖沉浸导航开/关 × 收起底栏开/关的四组配置。原生模式每组实际滚到底后，最后一行都保持 y=2112；每组做 3 次应用往返、下滑恢复、首页/我的切页和退出重进，末项位置稳定。原生底栏文字坐标保持一致，系统背景区继续正常延伸。宿主部分应用返回会自行复位“我的页”滚动位置，测试会再次滑到底核对终点。

动态正文、动态评论、视频主评论和评论详情覆盖上滑收起、下滑恢复、惯性滚动、键盘往返、切页及退出重进；沉浸导航开/关分别检查。收起后的实际列表下边界分别为 y=2285 / y=2340，截图核对后续内容可以绘制到释放区域，没有留下白色遮挡。主评论及评论详情各做 3 次应用往返，底栏高度稳定；实际滑到底的动态评论与有限回复线程均保留 41px 末项安全距离。

首次简单版回复末项脚本在末尾提示刚进入屏幕时停止，此时尚未到滚动极限；继续滑动到边界稳定后得到 41px 间距。后续末项检查要求连续滑动后提示坐标稳定，不将提示首次出现视为已经到达实际底部。

视频主评论样本未遍历全部评论，实际末项检查采用有限回复线程及动态评论；未实测其它设备、Android 8～14 或三键导航。这些范围不计为已完成实机测试。数据见 [device-validation-v112.json](device-validation-v112.json)。

“我的页”另在沉浸开/关两种配置下实测快速惯性滚动到极限，最后一行均为 y=2112，底栏收起及下滑恢复正常。简单版 APK 的三功能边界、无额外权限/provider、许可证副本检查通过。
