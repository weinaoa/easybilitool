# 1.1.14 直播状态栏修复

最终 APK：20 / `1.1.14`，SHA-256 `eaf41639c44c454e6259aa6cb517c827abb7d37af78e7ad067e80cfc07075a43`。

修复竖屏全屏直播画面顶部与状态栏下方的亮度断层，保留原生按钮安全距离和导航栏沉浸开关的独立行为。

## 标准接口与实现

遵循 Android 官方[边到边布局](https://developer.android.com/develop/ui/views/layout/edge-to-edge)与[窗口 Insets](https://developer.android.com/develop/ui/views/layout/insets)指导。API 35+ 的直播窗口使用 `WindowCompat.enableEdgeToEdge(window)`；API 30–34 使用 `WindowCompat.setDecorFitsSystemWindows(window, false)`。较旧系统保留既有兼容分支，本轮未实测。

画面延伸到状态栏，顶部交互控件通过真实状态 Insets 添加 padding。原生旧渐变遮罩在应用本功能时隐藏，退出后恢复，避免顶部亮度断层；可选保护由官方 `ProtectionLayout` / `GradientProtection` 绘制。关闭导航栏沉浸时，内容通过导航 Insets 保留底部距离，背景由官方 `ColorProtection` 处理。没有自行绘制或拉伸直播背景。
