- 26 个原 Java 模块文件及全部测试迁移至 Kotlin；现在有 29 个模块 Kotlin 文件、5 个测试 Kotlin 文件，模块和测试目录无手写 Java。AGP 9.1 内置 Kotlin，JVM 17；Gradle 构建脚本仍为 Groovy。
- 导航沉浸在 Activity 创建阶段准备窗口属性。暂停时保留仍可见的窗口状态，停止或销毁后还原，避免首页打开视频的过渡中提前恢复底部安全区。
- 首页安全区记录区分宿主原值与模块最近写入值，避免视频返回首页后重复加 55px。保留宿主实际改动和关闭时的还原。
